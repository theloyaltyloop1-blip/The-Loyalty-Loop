# Bundled card fonts

Downloaded 22 October 2026 from the Google Fonts repository. Each face is distributed under the accompanying SIL Open Font License; keep these license files with redistributed fonts.

- CardClassic: Cardo-Italic.ttf — https://github.com/google/fonts/tree/main/ofl/cardo
- CardHandwritten: PatrickHand-Regular.ttf — https://github.com/google/fonts/tree/main/ofl/patrickhand
- CardRetro: Anton-Regular.ttf — https://github.com/google/fonts/tree/main/ofl/anton
- Modern: existing BricolageGrotesque_700Bold dependency, already loaded by both apps.

Textures, stamp drawings, steam and barber-pole SVG geometry are authored in LoyaltyCard.tsx, not raster downloads or generated image assets.

# Production runbook

## Rollback
- **Website (Vercel):** Vercel dashboard → loyalty-loop → Deployments → pick the last good deployment → Promote to Production (instant, no rebuild). Or revert the commit on `main` and push.
- **Mobile OTA (EAS Update):** republish the previous commit's OTA to the `production` channel (`eas update --channel production --branch production` from the good commit), per platform. Native/store builds cannot be rolled back; ship a fix build.
- **Database (Supabase):** migrations are forward-only. Write a new reversing migration; do not edit applied ones. Back-to-stamps rollback: `update public.businesses set reward_model='spend_threshold'` and `alter table public.businesses alter column reward_model set default 'spend_threshold'`. For data loss, restore from backup (below) into a new project and copy rows back.
- **Edge functions:** redeploy the previous version of the function from git history.

## Backups (owner action: confirm in Supabase dashboard)
- Project `The Loyalty Loop` → Database → Backups: confirm daily backups are on; Pro plan adds PITR (recommended before launch). Do a test restore into a scratch project once.

## Monitoring (owner action: needs accounts)
- Uptime: add an external monitor (e.g. UptimeRobot/Better Stack) on https://the-loyalty-loop.com and the Supabase REST URL; alert to email/phone.
- Errors: add Sentry (web `@sentry/react`, mobile `sentry-expo`/`@sentry/react-native`) with a DSN set as an env var; not yet integrated in code.
- Vercel: enable deployment-failure notifications; Supabase: enable usage/error alerts.

## Pre-launch security to-dos (owner/review)
- Supabase Auth → enable leaked-password protection (dashboard setting).
- Revoke `anon`/`authenticated` EXECUTE on trigger functions `deliver_shop_announcement` and `notify_reward_redeemed` via a reviewed migration (advisor lint 0028/0029). Other SECURITY DEFINER RPCs are called by the apps; each must check `auth.uid()` internally.
- Tables with RLS but no policies (fidel_*, whatsapp_*, rpc_rate_limits, etc.) are service-role-only by design; confirm.

## Known unfixable-for-now audit items
- `braces` (via `shadcn` CLI, dev-only, no patched release) and Expo/React Native build-tool advisories: npm's only offered fixes are downgrades. Re-check with `npm audit` after Expo SDK upgrades.

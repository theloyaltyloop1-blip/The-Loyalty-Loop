# Which tools to adopt

Based on reading the vendors' own pages (2026-11-15). Nothing was installed or run, so this is a pricing/fit judgement, not a quality test.

| Tool | Verdict | Why |
|---|---|---|
| **Raylight** | Try it, once, for the phone-mockup hook shots | Web-based, so works on your Windows PC. Free plan is real but badges exports; badge removal or 4K needs a paid plan (from $12/mo). Only worth it if the 3D mockups beat what `/video-edit` inserts give you. Test with one reel before paying. |
| **Shotbase** | Skip | macOS-only and you are on Windows; free trial is 7 days, then export needs Pro. Its auto-zoom is a feature `/video-edit` punch-ins already approximate. |
| **AutoAE** | Skip for now | The install command runs code fetched from a website with no named publisher or source repository. Free tier is watermarked, 720p and non-commercial. `/video-edit` + HyperFrames already generates motion graphics from a description and is already set up. Revisit only if a source repo and a named company appear. |

**Default plan:** do everything in `/video-edit`. Treat Raylight as an optional insert for 3D phone mockups after one free trial.

Do not run `npx skills add https://autoae.online` without the owner's explicit approval.
